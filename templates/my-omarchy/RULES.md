# How a customization gets into this repo

## Where it goes

Classify every customization before saving it:

1. **Every machine.** A preference that should show up on each of your Omarchy machines. It goes under `config/`, and `install.sh` copies it into `~/.config/` everywhere.
2. **This machine only.** Something that names this hardware: its monitors, its keyboard, its Wi-Fi card. It goes under `hosts/<hostname>/`, and `install.sh` applies that folder only on the machine with that hostname.
3. **Not in git.** Secrets, tokens, keys, caches, logs, files generated by Omarchy, and files that still match the stock Omarchy copy.

Keep only your differences from stock. Never copy files out of `/usr/share/omarchy/` wholesale. Never edit `/usr/share/omarchy/`; `omarchy update` replaces it.

After a customization is applied on the live machine, say which of the three it was.

## Moving a change to another machine

On the machine where you made it:

```bash
./snapshot.sh            # copy live files back into the repo, and list new differences from stock
git add -A && git status
git commit && git push
```

On the other machine:

```bash
git pull
./install.sh
```

Pull before editing on the second machine, or the two copies of a shared file will diverge.

## Recipes

This repo follows omarchy-kitchen (`kitchen/settings.json`). The weekly review, publishing to the public cookbook, and applying or undoing recipes from other cookbooks all follow the `omarchy-kitchen` skill.

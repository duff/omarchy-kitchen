# {{name}}'s Omarchy cookbook

Customizations for [Omarchy](https://omarchy.org/), one problem per recipe. Each recipe says what stock Omarchy does, why, the change, how to check it, and how to undo it.

Every recipe lists the Omarchy version it was tested on, and the machines it fits. Changes go in `~/.config/`; none edit `/usr/share/omarchy/`.

To follow this cookbook, ask your agent to set you up with [omarchy-kitchen](https://github.com/duff/omarchy-kitchen) and follow `{{username}}/omarchy-cookbook`.
